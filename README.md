This README does NOT claim that all rooms below are free today.

VERIFY = listed as Free in the supplied research, but current Free-plan access was not established.

Do not use this README as proof that every listed room is free today.

What this roadmap is designed to do

The goal is to take a learner from zero cybersecurity knowledge toward advanced independent practice.

The progression is intentionally:

Learn the concept → complete the relevant walkthrough → reproduce the technique yourself → attempt a related challenge/CTF without the walkthrough → document the method → move to the next prerequisite.

Do not simply finish rooms as quickly as possible. A completed room with a walkthrough open beside you is not equivalent to independent skill.

How to use the order

W = Walkthrough / learning
C = Challenge / CTF

Within each phase, walkthrough material is placed before challenge material wherever the source identifies the room type.

For every skill:

Read/complete the walkthrough.

Close the walkthrough.

Reproduce the technique from memory.

Attempt the related challenge independently.

If stuck, identify the missing prerequisite rather than blindly copying a solution.

Retry the challenge.

Write down what worked, why it worked, and how to detect/prevent it.

Continue.

Current verification policy

Because the supplied research could not perform live per-room verification, the room rows below retain the source's historical Free label but are explicitly marked VERIFY unless a known current paid status has been identified.

This is deliberate. It is better to have a slightly annoying verification label than to tell a beginner that a room is free, send them into it, and discover a paywall halfway through the curriculum. Computers already waste enough of everyone's time.

Final readiness gate

Completing this roadmap does not make someone literally 100% ready for every cybersecurity job. Cybersecurity is too broad for that claim.

You are approaching independent practical readiness when you can:

use Linux and Windows confidently

understand TCP/IP, DNS, HTTP and common network services

enumerate systems methodically

perform basic authorized web-security testing

understand authentication and credential attacks

perform Linux and Windows privilege escalation in labs

understand Active Directory fundamentals

understand cloud and container security basics

analyze logs, PCAPs and common forensic artifacts

understand core cryptography

inspect basic binaries and malware behaviour

automate repetitive tasks with Python/Bash

solve unfamiliar Easy/Medium labs without walkthroughs

explain your attack or investigation path clearly

write professional technical reports

The real end state is not:

“I finished 648 rooms.”

It is:

“Give me an unfamiliar authorized environment and I can investigate it methodically.”
